SECRET FOUR — EDITING THE REFERENCE UI

Scenes
Open Assets/Scenes/Mainmenu.unity and Assets/Scenes/Game.unity.
If either scene was already open while files changed, reopen it to load the saved layout.
All panels, buttons, labels, fields, sliders, icons, and decorative images are saved scene objects, not a screenshot overlay or a runtime-generated replacement menu.

Hierarchy
Main menu screens: Canvas > [screen panel] > Safe Area > Content.
Gameplay: Canvas > TopHUD and Canvas > DirectionPanel.
Overlays: Canvas > Pausepanel, GameOverPanel, DisconnectPanel, SettingsPanel.
To preview an inactive screen in Edit mode, enable its panel and disable the other full-screen panels. Restore MainmenuPanel as the active menu before saving.

Inspector
Edit positions and sizes through RectTransform. Edit button/image sprites and colors through Image, and typography through the text component.
Localized text uses the key shown on LocalizedText. Change its wording in Assets/Resources/Localization/GameTextCatalog.asset; this keeps English, Spanish, French and Arabic editable and prevents runtime localization from replacing a one-language edit.
Dynamic names, room codes, turn instructions and results remain connected to the original controllers.
SettingsSelectionVisuals handles the selection check and mute-switch decoration only.
ResultPresentation exposes victory/draw layout positions and sizes in the Inspector.
ReferenceIcon exposes each vector icon shape and color in the Inspector.
PortraitBoardCamera keeps the world board aligned with width-scaled UI on taller phones; its reference size/aspect are editable.

Reusable artwork
Assets/Art/ReferenceUI contains the background, crown, sliced navy/gold frames, board cell, outline, circles and loading ring.
Assets/Prefabs/Cell.prefab is the editable source for board cells generated by the existing board system.
Store card/category/action prefabs retain their existing actions and use the matching frames.
The new dark board replaces the default board artwork. Existing selected alternative board and coin skins still apply. Select Classic board in Store to see the new default if a different skin is selected.

Scope
Game rules, AI decision code, networking, matching, coin placement/movement, win/draw resolution and audio settings logic were not changed.
The existing GameHUD only gained an Inspector switch that lets the new authored turn-label positions remain in place.
The top back buttons and loading Cancel reuse existing handlers. No new sharing service or networking behavior was introduced for reference-only share controls.

Validation
See design.txt, flow.txt and rules.txt in this directory for results.
